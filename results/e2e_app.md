# 应用负载端到端对比：H2D + 变换 + D2H（自研 vs CANN 原生）

> 硬件 Ascend910_9382（48 AIV）；reps=10；`--rounds 3` 逐点 min-of-means（与 `matrix_test.py` 同口径）。

> **应用负载模式** `--app all`：三方都喂**应用形状的输入**（自研 `AB_INPUT=<app>`、原生 `--input <app>`，C++ 与 numpy 同一套 xorshift32、**逐位同式**），仍然与各自双精度参考逐点比对（判据 1e-4）。

> * **ofdm** —— 多载波通信 / 频域均衡（16-QAM 子载波，DC/保护带置零）；形状 n ∈ {2048,4096} × batch ∈ {14,140}，搬运量 16·n·batch 字节。

> * **radar** —— 雷达成像距离门（4 目标复指数回波 + 逐脉冲多普勒相位）；形状 n ∈ {1024,2048} × batch ∈ {64,256}，搬运量 16·n·batch 字节。

> * **dl** —— 深度学习频域层（每 8 点一块的复激活）；形状 n ∈ {1024,4096} × batch ∈ {32,128}，搬运量 16·n·batch 字节。

> 

**口径**（三路逐段对应，计时区外均剔除进程/框架启动与输入生成）：
1. `自研` = H2D → `kfft_fwd` → D2H（复数→复数，`fft_check AB_E2E=1`）
2. `原生` = `xd.copy_(x_cpu)` → `torch.fft.fft(xd)` → `yd.copy_(out)`（源/目的均 pinned）（复数→复数，torch_npu op-plugin 内核）

3. `裸 CANN aclRfft1D` —— **应用负载模式下跳过**（实→复、搬运量减半，与这三类应用不可比；网格口径的三方对比见 `results/e2e.md`）

 
**表1 的 `E2E 比值 > 1` 表示自研更快**；只算 kernel 的 `device 比值` 见 `matrix_test_a7.md`。

- 正确性：**12/12 PASS**（maxRel ≤ 1e-4）
