  kfft_r2c_post_static: 304.3 µs avg  (51 tasks)

## Fused (kfft_r2c_fwd)
  kfft_r2c_fwd: 1361.4 µs avg  (51 tasks)
  Total device:  69432 µs

## Key Finding
Static paired writer is 2.5x slower than baseline post kernel.
Root cause: baseline uses L/U segment split + double buffering;
static uses single-chunk paired writer without overlap.
Fused kernel bottleneck is scalar simple_fft (O(n^2)), not writer logic.
