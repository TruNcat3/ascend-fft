# 实验对比（当前入口）

本文件曾保存早期 A7/v2 时代的长表和图注。那些数字使用旧快照或旧统计口径，容易与当前
加固发布结果混淆，因此不再作为现行结论。

请按下面顺序阅读：

1. [当前实验结果](benchmarks/results.md)：当前快照、收益汇总、负点和实验边界；
2. [C2C 发布矩阵](generated/current_matrix.md)：49 个 `N × batch` 点的逐点数据；
3. [多基线发布明细](generated/current_comparison.md)：CANN、CPU 和实数路径的上下文对比；
4. [复现实验](benchmarks/reproducibility.md)：如何重新运行、校验和发布快照。

当前发布快照为 `ascend910_9382-revalidation-20261010`。在 Ascend910_9382 / CANN 9.0.0
上，C2C device-only 几何均值为 **1.62x**，49 点中 48 点严格领先；C2C E2E 为 **1.36x**，
应用 shape E2E 为 **1.42x**。R2C/C2R 的对称 5-trial 结果分别为 **1.18x** 和 **1.78x**。
唯一 C2C 严格回退点 `N=1024,batch=4096`（0.96x）以及 R2C 的负点都保留在当前数据和图表中。

本仓库是 cuButterfly 的 Ascend 迁移实例。实验目标是在预先声明的范围内证明方法可迁移并带来
可复现收益，不是把所有硬件和尺寸都优化到全局最优；范围内的回退点会进入下一轮定向优化，
不会通过删点或改变统计口径隐藏。
